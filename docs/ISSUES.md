### 2026-09-04 (сессия) — v0.8.0 подготовлен: чат на 1 запрос + быстрый дашборд
- **Деплой 1:** чат через `POST /api/chat/init` → RPC `get_chat_data` (было 5–7 запросов). Fallback `legacyInit`, чат не ломается.
- **Деплой 2:** `src/lib/auth-cache.ts` — `getServerClient`/`getCurrentUser` через `React.cache()`; все серверные дашборд-страницы переведены (было 3×`getUser` + 2×`profiles`, стало 1+1 на запрос).
- **B7 отклонён:** `revalidate` не даёт ISR (кастомный `supabaseFetch` без `next:{revalidate}`), риск устаревания контента учителя.
- Проверка: `tsc --noEmit` чисто, `npm run build` успешен. Браузерное регресс-тестирование (вход, курсы, урок, чат, настройки, учительская) — 0 ошибок.
- **Деплой: `73e60ff` → ревизия `deploy-1788547720` (ACTIVE)** — v0.8.0 на проде, `/api/chat/init` и `/api/stats` отвечают 401 без авторизации (корректно).
- **Гигиена:** YCR очищен до 2 тегов (`deploy-1788548226`, `deploy-1788547720`). Новая ишью #39 (холодный старт на проде, низкий приоритет).
